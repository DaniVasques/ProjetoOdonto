# OdontoRio

Landing page responsiva de uma clínica odontológica, desenvolvida como projeto de estudo e portfólio a partir de um layout no Figma.

## Tecnologias

- HTML semântico e CSS responsivo
- JavaScript nativo
- Swiper para o carrossel de depoimentos
- IntersectionObserver e Web Animations API para animações de entrada

## Recursos

- Layout adaptado para desktop, tablet e mobile
- Menu mobile com navegação por teclado e fechamento com Escape
- Seções de apresentação, serviços, agendamento, depoimentos e contato
- Footer com redes sociais e mapa com acesso ao Google Maps
- Animações sutis com suporte a `prefers-reduced-motion`

## Como executar

Abra `style.html` no navegador ou utilize um servidor estático, como a extensão Live Server do VS Code. Não é necessário instalar dependências nem executar um build.

As fontes do Google Fonts e os arquivos do Swiper são carregados por CDN e precisam de conexão com a internet. O conteúdo principal permanece disponível caso o carrossel não carregue.

## Referência visual

A implementação preserva a identidade visual do exercício e mantém o nome do responsável e os seis serviços consistentes entre desktop e mobile.

## Observações

Projeto demonstrativo de portfólio. Textos, imagens e dados de contato vêm do exercício original; não representam uma integração real de agendamento. Os botões levam à seção de contato. Instagram e X permanecem sem links até que os perfis oficiais sejam informados.

O mapa utiliza o asset do Figma e abre o endereço no Google Maps. As imagens e a referência visual não têm uma licença de redistribuição declarada neste repositório.
